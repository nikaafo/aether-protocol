A transport protocol for the next generation

Aether is an L4 transport protocol built for multiplexing, encryption, multi-path routing, and self-sovereign identity — without the overhead of TCP.

Get Started View on GitHub

Why Aether?

Modern networks demand more than TCP and UDP can provide.

Multiplexing

Multiple logical streams over a single connection without head-of-line blocking.

Encryption by Default

All traffic is encrypted and authenticated using modern cryptographic primitives.

Multi-Path

Use multiple network paths simultaneously for better throughput and reliability.

Self-Sovereign Identity

Built-in peer identity without centralized CAs or certificate authorities.

Low Latency

Optimized for real-time applications: gaming, VoIP, distributed systems.

Open Source

Fully open protocol and reference implementation. No vendor lock-in.

Quick Start

Run the Aether Gateway in under a minute.

git clone https://github.com/nikaafo/aether-protocol.git
cd aether-protocol/aether-gateway
cargo run --release -- --target 127.0.0.1:8080
